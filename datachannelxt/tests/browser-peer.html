DataChannelXT browser peer

The browser half of runbook row 40. Signaling is copy/paste, one blob each way (type, a line break, then the SDP with its candidates). Procedure: datachannelxt/docs/browser-interop.md. Status: idle

Checks

    1. Paste the OXT blob here

    An offer (the main path: OXT ran bpOffer) makes this page answer. An answer completes an offer this page made.

    2. Copy this blob back to OXT

    Appears once ICE gathering completes (non-trickle), then bpAccept or bpAnswer reads it from the clipboard.

    3. Talk

    The test pair is the string hello from the browser and the bytes ff fe 80 7f 01 00 as an ArrayBuffer; the OXT script checks that one arrives as text and the other as a payload.

    ICE servers (optional)

    One per line, the same forms as dcCreatePeer: stun:host:port, turn:user:pass@host:port?transport=udp. Leave empty on one machine or a LAN, as the runbook does.
