# Getting help with the xTalk Suite

- **Start with a member's README.** Each member's `README.md` is its
  front door: what it does, how to install it, and a getting-started
  guide where it has one (for example `sodiumxt/docs/getting-started.md`).
- **See it run.** Follow [Start here](README.md#start-here-no-experience-needed)
  in the README: one stack opens every demo, sample and harness in place.
  OXT-Beyond's examples include a Learn stack for each extension, with
  live lessons.
- **Questions and discussion:** the
  [OpenXTalk forums](https://openxtalk.org/forum/).
- **A bug or an idea:** open an
  [issue](https://github.com/SethMorrowSoftware/xtalk-suite/issues/new/choose)
  with the form that fits. Say which member, its version, your IDE and
  engine version, and your operating system (32- or 64-bit).
- **A problem that only happens in OXT-Beyond**, with an extension that
  works elsewhere: report it to
  [OXT-Beyond](https://github.com/SethMorrowSoftware/OpenXTalk-Beyond/issues).
- **A security problem:** never in a public issue; see
  [SECURITY.md](SECURITY.md).

This is a volunteer project. There is no paid support and no guaranteed
response time, but every report is read.
